# keil-bridge

English | [简体中文](README_zh.md)

Convert Keil MDK (ARM-ADS, armcc 5 / armclang 6) projects to `arm-none-eabi-gcc` + `make` projects, and backport edits made in the new project back to the Keil project using each file's original character encoding and line endings.

Only common patterns are handled; any unrecognized configuration or syntax produces a warning or error (with `file:line`) rather than guessing.

## Installation

```sh
uv tool install .        # or run locally with: uv run keil-bridge ...
```

Requirements: Python ≥ 3.11 (standard library only); building requires `arm-none-eabi-gcc` and `make`.

## Usage

```sh
keil-bridge convert path/to/Project.uvprojx out-dir [--target NAME] [--set KEY=VALUE ...] [--config x.toml] [--no-git]
cd out-dir
make                       # build/<name>.elf, .hex, .bin
make flash                 # st-flash; FLASHER=pyocd / FLASHER=openocd OPENOCD_ARGS=...
keil-bridge status         # M modified locally / K modified in Keil / C modified in both / ? new file
keil-bridge backport --dry-run
keil-bridge backport       # write back to Keil project; conflicts are rejected unless --force
keil-bridge regen --set c_std=gnu99 --set optimize=-Os   # change options and regenerate keil-bridge/
keil-bridge regen --unset c_std
```

## What Gets Converted

- Source files (`.c`, `.h`, `.s`, `.cpp`, `.hpp`, `.inc`) under the project root (common ancestor of the `.uvprojx` file and all referenced source and include directories) are converted to UTF-8 + LF. Original encodings are detected among ASCII / UTF-8 / GBK; GBK requires that re-encoding the decoded text recovers the exact original bytes. Build artifacts and IDE state files are not copied, and are listed in `CONVERSION.md`.
- `keil-bridge/` (generated by the tool; rewritten completely on `regen`):
  - `project.mk`: Source files, macro definitions, include paths, and CPU flags extracted from the `.uvprojx` Target settings.
  - `startup_*.c`: Vector table and weak interrupt handlers translated from the armasm startup file.
  - `<device>.ld`: Linker script generated from IROM1/IRAM1 and Stack_Size/Heap_Size in the startup file.
  - `keil_compat.h`: Force-included via `-include` to map `__align`, `__weak`, `__forceinline`, `__irq`, etc.
  - `syscalls.c`: Newlib stub functions; if the project overrides `fputc` (Keil's convention for redirecting `printf`), `_write` automatically forwards to it.
  - `include-shims/`: Forwarding headers for case-insensitive `#include` mismatches, avoiding edits to original source code.
  - `manifest.json`: Stores each file's original encoding, line endings, and hashes for use by `status` and `backport`.
- Root directory: `Makefile` (generated only when missing; can be customized), `keil-bridge.toml` (override options), `compile_commands.json`, `CONVERSION.md` (options mapping table and full diagnostics), `.editorconfig`, and `.gitignore`.
- By default, initializes a Git repository (`git init`) and creates an initial commit.

During conversion, every source file is preprocessed with GCC (so code inside `#if defined(__CC_ARM)` branches will not trigger false positives), checking for armcc-specific constructs: `__asm` inline assembly, `__packed`, `__svc`, `__nop()` and other intrinsics, `#pragma import`, etc.

## Configuration Overrides

Precedence: uvprojx defaults < `keil-bridge.toml` < `--set`. Values passed via `--set` are saved into `keil-bridge.toml`.

| Key | Type | Description |
|---|---|---|
| `c_std` | string | `gnu90`, `gnu99`, `gnu11`, etc.; Keil C90 mode corresponds to `gnu90` |
| `optimize` | string | `-O0` … `-O3`, `-Os`, `-Og`, `-Oz`, `-Ofast` |
| `warnings` | string | `default`, `none`, `all` |
| `defines`, `undefines`, `includes`, `sources` | list of strings | Can also be modified using `<key>_add` and `<key>_remove` |
| `cpu`, `fpu`, `float_abi` | string | e.g. `cortex-m4`, `fpv4-sp-d16`, `hard` |
| `signed_char`, `short_enums` | boolean | |
| `flash_origin`, `flash_size`, `ram_origin`, `ram_size`, `stack_size`, `heap_size` | integer | |
| `startup` | string | armasm startup file to translate; set to `""` to provide your own GCC startup file (added via `sources_add`) |
| `linker_script` | string | Use your own linker script instead of generating one |
| `extra_cflags`, `extra_asflags`, `extra_ldflags`, `libc_specs` | list of strings | |

When an option is overridden, conversion warnings associated with that option are silenced (for example, setting `extra_cflags` silences warnings about unmapped `MiscControls`).
For temporary adjustments, flags can also be passed directly to make, e.g. `make OPT=-O2 CSTD=gnu99 EXTRA_CFLAGS=-Wall`.

## Backport Rules

- Only source files recorded in the manifest are written back. Newly added or deleted files only trigger warnings; the `.uvprojx` file is not modified.
- Files that were originally ASCII but have non-ASCII characters added are written back as GBK. If a character cannot be represented in GBK (e.g. emojis), an error is reported and the file is not written back.
- Files with mixed CRLF/LF line endings originally are normalized to CRLF when written back (a notice is shown during conversion).

## Unsupported Features

Non-ARM toolchains such as C51; C++; armcc `.lib` / `.o` binary archives; ROPI / RWPI; scatter loading files (a generated linker script will be used instead, with a warning); RTE components; IROM2 / IRAM2 and off-chip memory regions; per-file or per-group compiler flags.
